# BCG token metadata

The BCG token's metadata, served by GitHub Pages at
**[twtunde.github.io/bsg-platform/assets/bcg.json](https://twtunde.github.io/bsg-platform/assets/bcg.json)**: the
address written into the BCG Jetton master on TON mainnet
([`EQDsrOJ3-TqJpc1Vx5bD9rMCe1bJ_UVwMM5-AZr92fvSsvb6`](https://tonviewer.com/jetton/EQDsrOJ3-TqJpc1Vx5bD9rMCe1bJ_UVwMM5-AZr92fvSsvb6)).
Wallets and explorers read the token's name, symbol, decimals and logo from it.

- `assets/bcg.json`: the TEP-64 metadata.
- `assets/brand/`: the token's logo and the brand images.
- Every other address on this site forwards to the BCG documents at
  [twtunde.github.io/bcg-docs](https://twtunde.github.io/bcg-docs/), where the contract source can also be checked
  against the chain.

This repository must stay public and keep its name: the address above is fixed in the token contract.
